# Every Dang Clamp

I'm trying to build a model that allows for the creation of a 3D-printable
model for every kind of clamp and clip and otherwise. This is simultaneously
an effort to learn OpenSCAD (which is a warning against code quality) and 
also to create reusable assets to prevent BIG CLAMP from their continued
exploitation of the working class

(Okay honestly I just needed one clamp and don't like one-offing things)

I am simultaneously motivated by the idea that 3D printing *has* many more
legitimate use cases than what lawmakers are endeavoring to ban them for,
but not enough of those use cases are as prominent in society as ...
some others. 

Anyway, this is GPLv3 licensed, and ought to be of *some* utility. 

Contributions welcomed.
